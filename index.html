Tentang Saya

Seorang Data Analyst berpengalaman di industri Internet Service Provider (ISP) dengan fokus mendalam pada Customer Value Management (CVM). Berpengalaman dalam mengolah data pelanggan aktif, menganalisis pola pembayaran (payment behavior), mengelola strategi retensi end-to-end, hingga merancang Churn Modeling presisi tinggi untuk memitigasi kehilangan pelanggan dan memaksimalkan Customer Lifetime Value (CLV).

Keahlian Utama (Core Competencies)

  • Customer Value Management (CVM): Segmentasi pelanggan, analisis siklus hidup pelanggan (Lifecycle Analysis), dan personalisasi penawaran promo.
  • Churn Prediction & Modeling: Mengembangkan model proyeksi churn berbasis status freeze dan pembayaran untuk deteksi dini risiko berhenti langganan.
  • Retention Strategy & Operations: Manajemen eskalasi tim retensi, otomatisasi voice bot, dan penanganan kunjungan lapangan (retention visit).
  • Data Analytics & Tools: SQL, Excel Power Query, Dashboard Visualization (Chart.js, DataTables, Glassmorphism/Dark Mode UI), dan integrasi pipeline data SFTP.

Pengalaman & Proyek Strategis

1. Proyeksi Churn Modeling & Pipeline Otomasi Data

Deskripsi: Membangun dan mengoptimalkan alur data (pipeline) dari server SFTP untuk memantau status freeze pelanggan secara real-time.

Kontribusi Utama:

  • Mengintegrasikan analisis churn berdasarkan status freeze pelanggan guna meningkatkan akurasi prediksi.
  • Menerapkan sistem tindak lanjut otomatis (Voice Bot) pada periode kritis ($H+3$ dan $H+25$) serta eskalasi terstruktur ke tim retensi.

2. Customer Retention & Payment Behavior Analysis

Deskripsi: Menganalisis kebiasaan pembayaran pelanggan aktif untuk mengidentifikasi potensi penunggakan (arrears) sejak dini.

Kontribusi Utama:

  • Merancang skenario penanganan retensi dan skrip penawaran khusus untuk pelanggan berisiko tinggi.
  • Mengelola evaluasi efektivitas promosi periode freeze guna memastikan strategi pemasaran selaras dengan tingkat retensi bulanan.

3. Optimalisasi Dispatcher & Sistem Operasional CVM

Deskripsi: Mengembangkan logika Auto Dispatcher untuk distribusi tiket penanganan pelanggan agar beban kerja agen lebih seimbang (Least Busy Agent).

Kontribusi Utama:

  • Meningkatkan efisiensi respons tim Customer Response (CRT) dan Retention Visit dalam menangani eskalasi pelanggan secara cepat dan tepat sasaran.

Technical Preview: SQL & Pipeline Logic

Contoh cuplikan query SQL untuk analisis status freeze dan identifikasi pelanggan berisiko tinggi di server SFTP.

SQL Query: Freeze Churn Prediction Extraction ($H+3$ & $H+25$)

SELECT customer_id, region, package_tier, freeze_days, payment_status, CASE WHEN freeze_days >= 25 THEN 'High Risk (H+25)' WHEN freeze_days >= 3 THEN 'Medium Risk (H+3)' ELSE 'Normal' END AS risk_category FROM sftp_customer_freeze_logs WHERE status_date = CURRENT_DATE() AND freeze_days >= 3 ORDER BY freeze_days DESC;

Python / SQL Logic: Auto Dispatcher (Least Busy Agent)

# Logika penugasan otomatis tiket retention ke agen dengan beban kerja paling sedikit def get_least_busy_agent(agent_pool): active_load = db.query("SELECT agent_id, COUNT(ticket_id) as active_tickets FROM tickets GROUP BY agent_id") # Pilih agen dari pool dengan tiket aktif paling sedikit optimal_agent = min(agent_pool, key=lambda a: active_load.get(a, 0)) return optimal_agent;
